## Tecnologias
- Node.js + Express
- MySQL
- JWT
- bcrypt

## Como rodar
1. Clone o repositório
2. Instale as dependências: `npm install`
3. Crie um arquivo `.env` baseado no `.env.example`
4. Rode o servidor: `npm run dev`
